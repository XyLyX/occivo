# OCCIVO — The Art of Thoughtful Gifting

Dubai-first, premium gifting concierge pilot. This repository contains the **initial website foundation**, not a live checkout or completed end-to-end marketplace.

## Current features

- Responsive Warm Editorial homepage, contact page and draft privacy notice.
- Four-question gifting brief with three distinct concept directions.
- AI-assisted recommendations when a server-side API key is configured; clearly labelled illustrative fallback when it is not.
- Gifting request form intended for secure Netlify Forms capture after site connection and validation.
- Public customer contact channels: hello@occivo.com, concierge@occivo.com, orders@occivo.com and support@occivo.com.
- **No checkout, confirmed inventory, guaranteed prices or delivery commitments.** Human sourcing checks remain mandatory.

The administrative master mailbox is private and is intentionally not listed in public-facing assets.

Read [DEPLOYMENT.md](DEPLOYMENT.md) for setup, privacy and accessibility release gates.
